AI 醫生助手 — 可攜版使用說明
========================================

【快速開始】

  1. 把整個文件夾解壓到任意位置（例如 D:\ 或桌面）
     注意：路徑最好不要包含中文或空格

  2. 雙擊  start.bat

  3. 等待 20~40 秒，瀏覽器會自動打開 http://localhost:5173

  4. 首次使用：點「立即註冊」建立賬號 → 登錄 → 開始錄音轉寫


【停止服務】

  雙擊  stop.bat

  注意：服務啟動後在後台運行（沒有彈出窗口），
        關閉任何窗口都不會停止服務，必須用 stop.bat。


【系統要求】

  - Windows 10 / 11（64 位）
  - 內存建議 8GB 以上
  - 無需安裝 Python、Node.js、ffmpeg（全部已內置）
  - 無需聯網（Whisper 語音模型已內置）


【常見問題】

  1. 雙擊 start.bat 窗口一閃就沒了
     → 通常是沒有完整解壓。請先把 ZIP 完整解壓到文件夾，
       再從解壓後的文件夾裡雙擊 start.bat，不要在 ZIP 裡面直接雙擊。

  2. 頁面顯示 Failed to fetch
     → 後端還在加載模型，等 20~40 秒後按 F5 刷新頁面即可。

  3. 提示端口 8000 / 5173 被佔用
     → 先雙擊 stop.bat，再雙擊 start.bat。

  4. 轉寫速度慢
     → 在頁面右上角的「模型」下拉裡選擇更小的模型（tiny / base）可提速。

  5. 想換用其他模型
     → 右上角「模型」下拉裡選擇；未下載的型號首次使用需要聯網。


【文件夾說明】

  backend\     後端服務（內含 Python 運行環境、ffmpeg）
  frontend\    前端網頁
  node\        內置 Node.js
  models\      Whisper 語音識別模型（medium）
  scripts\     啟動器（請勿刪除）
  start.bat    一鍵啟動
  stop.bat     停止服務
  .tmp\        運行日誌（可忽略）


【數據與隱私】

  - 音頻和文本只保存在本機，不會上傳到任何服務器。
  - 用戶數據庫：backend\data\users.db
  - 全部本地部署，適合內部網絡使用。
