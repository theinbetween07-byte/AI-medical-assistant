语音识别与转录实现

默认使用本机 faster-whisper small（CPU int8，音频不出本机）。工具条「模型」下拉内置 small，另有 Qwen3-ASR、Whisper medium、Whisper large-v3 扩展；未安装项会弹出下载地址与步骤，不会联网下载。CapsWriter 高精度档在病理术语上更准，但耗时更长。

维度 默认：faster-whisper 可选：CapsWriter-Offline
系统 Windows / macOS / Linux，需 ffmpeg 仅保证 Windows 10/11 64 位，需 VC++ 运行库与 ffmpeg
CPU 4 核起，无需独显 无独显可用 SenseVoice-Small / Fun-ASR-Nano
内存 约 2 GB 量级 官方未给统一门槛，模型包 0.5–1.5 GB
显卡 非必需；CUDA 可选，约 1.5–2 GB 显存 可选 DirectML / Vulkan；显存 <1 GB 至 1–2 GB

两条路径都在本机处理音频；切换前请在同一批语料上比较准确率与耗时。项目内尚未接入 CapsWriter 适配层。

选型建议

  • 有 8 GB 显卡：综合选 medium；病理长术语选 large-v3 或 Qwen3-ASR。
  • 无显卡：8 核选 small；4 核或内存 ≤8 GB 选 SenseVoice。
  • 噪声或长音频：medium 最稳；large-v3 在噪声下退化，需前置降噪。

完整数据表与局限见 outputs/ui-integration/asr-benchmark/REPORT.md；合成语料，结论为方向性。
