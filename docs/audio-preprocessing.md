# ASR 音频预处理规范

> 适用版本：MedScribe HK 集成层（`medscribe-allinone/app/integration`）
> 代码入口：[audio_prep.py](../medscribe-allinone/app/integration/app/audio_prep.py)
> 实测报告：[outputs/audio-preprocess/REPORT.md](../outputs/audio-preprocess/REPORT.md)

## 1. 目标与边界

**目标**：在转写前把格式、噪声、混响、响度、长静音等差异收敛到 ASR 模型的舒适区，减少因录音条件造成的识别波动。

**不做的事**：

- 不做说话人分离（diarization）。多人场景只做启发式标记，转写文本仍由单模型输出。
- 不做强压缩、限幅、EQ、音色美化。这些会改变语音的谱包络或动态，通常损害 ASR。
- 不追求"听感更好"。所有参数以**不提高 WER** 为约束，而不是以听感为目标。
- 不覆盖原始录音。预处理结果另存为 `{session_id}.asr.wav`，原始 `{session_id}.wav` 保留。

**执行时机**：在项目界面点击「转写」后、调用上游 ASR 之前自动执行。上传阶段仍只做格式统一与时长/静音校验。

## 2. 流程总览

```text
上传音频 (wav/mp3/wma/m4a/...)
   │
   ├─ 上传阶段：ffmpeg 统一为 16 kHz / mono / s16 WAV（快速转码 + 静音校验）
   │
   └─ 点击转写
        ├─ 1. 诊断（ffprobe + astats + ebur128 + silencedetect）
        ├─ 2. 场景启发式判断（电话 / 远场 / 疑似多人 / 近场单人）
        ├─ 3. 条件化处理链
        │     highpass(80 Hz) → [降噪 afftdn] → [去混响 afwtdn]
        │     → loudnorm 两遍（线性优先）→ VAD 首尾/超长静音裁剪
        ├─ 4. 输出 16 kHz / mono / pcm_s16le
        ├─ 5. 处理后复测，生成前后指标对比 JSON
        └─ 6. 交给 ASR；失败时回退原始 16 kHz WAV，不阻断转写
```

## 3. 属性检查项

| 属性 | 测量方式 | 判定/用途 |
| --- | --- | --- |
| 文件格式 / 编码 | `ffprobe -show_streams` | 决定解码器；压缩格式无固定位深 |
| 采样率 | ffprobe `sample_rate` | 8 kHz 判定电话窄带；非 16 kHz 需一次重采样 |
| 声道数 | ffprobe `channels` | 多声道下混；立体声通道差异大时提示多人/双麦 |
| 位深 | ffprobe `bits_per_sample` | 压缩格式返回 0，记作 `compressed` |
| 时长 | `format.duration` | 与 BR-01（≤15 min）一致 |
| 峰值电平 | `astats` Peak level dBFS | 接近 0 dBFS 提示削波风险 |
| 整体响度 | `ebur128` Integrated LUFS | 与目标响度比较，决定 loudnorm 增益 |
| 真峰值 | `ebur128` True peak | loudnorm 的 TP 约束依据 |
| 是否削波 | Peak + Flat factor + Peak count | 削波不可逆，只警告并避免二次失真 |
| 直流偏移 | `astats` DC offset | 偏高时由 80 Hz 高通顺带去除 |
| 静音占比 | `silencedetect` 静音段求和 / 总时长 | > 60% 警告；决定是否 VAD 裁剪 |
| 背景噪声类型 | 帧 RMS 分布 + 场景特征 | 稳态噪声适合 afftdn；脉冲噪声不适合 |
| 估计信噪比 | 帧 RMS 的 P90 − P10 | 降噪/去混响的门控主判据 |
| 多人 / 远场 / 电话 | 启发式（见 §4.6） | 只标记与调参，不做分离 |

**关于 SNR**：没有干净参考信号时不存在严格 SNR。这里用 100 ms 帧 RMS 的 P90（语音电平）与 P10（噪声底）之差作为**估计值**，并在报告中标注 `snr_db_est`。它受增益和静音段数量影响，绝对值不可与仪器 SNR 直接比较，只用于同一文件处理前后的相对比较和门控。

## 4. 分步处理

### 4.1 格式统一（必做）

| 项 | 值 |
| --- | --- |
| 工具 | ffmpeg |
| 输出 | 16 kHz / 单声道 / `pcm_s16le` WAV |
| 重采样次数 | 1 次（解码即统一，后续全部在 16 kHz 域） |

**依据**：Whisper 系列按 16 kHz 单声道训练，faster-whisper 内部也会重采样到 16 kHz。提前统一可以避免上游使用不确定的默认重采样器，并让 VAD/测量在同一域进行。

**适用条件**：所有输入。

**负面影响**：8 kHz 电话录音升采样到 16 kHz 不会增加信息，只是格式适配；多声道下混可能引入相位抵消，但 ASR 本来就只接受单声道，下混优于任取一路。

### 4.2 高通 / 去直流（默认必做）

| 项 | 值 |
| --- | --- |
| 工具 | `highpass=f=80:poles=2` |
| 关键参数 | 截止 80 Hz，二阶 Butterworth |

**依据**：成人语音基频约 85–255 Hz，80 Hz 以下主要是直流、桌面震动、空调低频隆隆与风噪，对识别没有贡献。

**适用条件**：默认开启；`MSHK_PREP_HIGHPASS_HZ=0` 可关闭。

**负面影响**：极低音男声的基频下限可能接近 80 Hz，二阶高通在该点仅 −3 dB，实践中影响可忽略；若录音本身带宽已很窄，可关闭以避免叠加滤波。

### 4.3 轻度降噪（条件触发）

| 项 | 值 |
| --- | --- |
| 工具 | `afftdn`（FFT 谱减 + 噪声跟踪） |
| 关键参数 | `nr=10`（上限 12）、`nf=实测噪声底+2`（钳制 −80…−20）、`tn=1` |

**技术依据**：afftdn 对稳态噪声（空调、风机、电源嗡声、持续白噪）有效；`tn=1` 让噪声底随时间跟踪，适应缓慢变化。

**适用条件（校准后）**：估计 SNR < 19 dB 时启用；噪声底 > −30 dBFS 时强制启用。阈值来自带参考文本的 A/B 实验：

| 语料 | 估计 SNR | 不降噪 WER | 降噪 WER |
| --- | --- | --- | --- |
| 15 dB 白噪 | 28.1 | **0.095** | 0.135 |
| 5 dB 白噪 | 16.2 | 0.108 | **0.081** |

15 dB 时降噪反而更差，因此不能"见噪声就降"。这正是条件化门控存在的理由。

**负面影响**：降噪会削弱弱辅音、气声和词尾；过强会引入"音乐噪声"（musical noise），使模型插入/替换词。`nr` 上限 12 dB 是硬约束。

### 4.4 去混响（条件触发，默认仅极低 SNR）

| 项 | 值 |
| --- | --- |
| 工具 | `afwtdn`（小波域抑制） |
| 关键参数 | `sigma=0.03`、`levels=6`、`percent=0` |

**必须说明的局限**：ffmpeg **没有**真正的去混响算法（WPE / NARA-WPE / DeepFilterNet 才是）。`afwtdn` 只能抑制混响尾音和残余噪声。真实强混响环境（大厅、瓷砖房间、远场麦克风）应外接专用模型离线处理，或改用带 `vad_filter` 的流式 ASR。

**适用条件**：估计 SNR < 12 dB 时启用；`MSHK_PREP_DEREVERB=off` 可完全关闭。

**负面影响**：小波抑制过强会让声音发闷、辅音模糊。A/B 实验（5/15 dB 白噪，无真实混响）中它未带来额外收益，也未造成损害；因此在真实混响证据不足时保持保守阈值。

### 4.5 响度归一化（必做，线性优先）

| 项 | 值 |
| --- | --- |
| 工具 | `loudnorm`（EBU R128，two-pass） |
| 目标 | `I=-20 LUFS`（可配 −23）、`TP=-2 dBFS`、`LRA=30` |
| 模式 | `linear=true` + 第一遍测量值；不可行时才回退动态模式 |

**技术依据**：ASR 对绝对音量不敏感（模型内部有归一化），但 VAD 阈值、能量门限和不同录音之间的行为一致性依赖响度。实测样本的原始响度跨越 **−10.3 到 −24.1 LUFS（约 14 LU）**，归一化后全部落在 −20 ± 0.3 LUFS。

**关键修正**：`LRA` 是"允许的最大响度范围"，不是"要压到的范围"。若设为广播标准的 11 LU，原始 LRA 12.9 的录音无法线性归一化，loudnorm 会自动回退到动态模式并压缩到 4.4 LU。放宽到 30 后，同一文件 LRA 保持 12.9→13.0。ASR 不需要压动态，因此 `LRA=30` 是更安全的选择。

**负面影响**：动态模式会压缩动态范围，可能抹平弱音节；因此报告会对比处理前后 LRA，若下降超过 30% 给出警告。目标响度不要设得过高（如 −16 LUFS），否则会把噪声一起抬起来。

### 4.6 VAD / 静音裁剪（默认只裁首尾与超长中间静音）

| 项 | 值 |
| --- | --- |
| 工具 | `silencedetect` 检测 + `atrim`/`concat` 精确裁剪 |
| 关键参数 | 阈值 −38 dBFS、最短静音 0.55 s、保留 250 ms 余量、中间静音 >8 s 才压缩 |

**依据**：Whisper 在长静音上容易产生幻觉（重复句、字幕版权句、凭空补词）。裁掉首尾静音可以缩短输入并降低幻觉概率，同时不改变中间语流。

**时间轴**：裁剪后 ASR 返回的时间是相对处理后音频的。报告中的 `time_map` 会把每段的 `start_ms/end_ms` 映射回原始时间轴，前端显示的时间戳仍然对应原始录音。

**适用条件**：`MSHK_PREP_VAD=false` 可关闭；中间静音阈值 `MSHK_PREP_MID_GAP_MS` 可调。

**负面影响**：裁切过激会切断弱起音、呼吸声和词头。因此默认只处理首尾和 >8 s 的超长静音，保留 250 ms 余量；报告会对比"有效语音时长"，减少超过 20% 时告警。

### 4.7 按语句切分（默认不启用）

上游 faster-whisper 自带 VAD 与分段，重复切分通常无收益，还会破坏跨句上下文（医学术语、否定范围）。`silencedetect` 的语音段清单已写入报告，需要外接切分时可据此生成。

## 5. 条件化决策规则

| 步骤 | 触发条件 | 默认 |
| --- | --- | --- |
| highpass | 始终 | 开 |
| denoise | 估计 SNR < 19 dB 或噪声底 > −30 dBFS | auto |
| dereverb | 估计 SNR < 12 dB | auto |
| loudnorm | 始终（已是 16 kHz/mono/s16 且响度达标时直接复制） | 开 |
| VAD 裁剪 | 有可识别语音段 | 开 |
| 中间静音压缩 | 单段静音 > 8 s | 开 |
| 语句切分 | 从不自动 | 关 |

所有决策、参数、判定依据写入 `{session_id}.prep.json` 的 `decisions` 字段，便于复现和追责。

## 6. 负面效应清单

| 处理 | 可能的负面影响 | 规避 |
| --- | --- | --- |
| 降噪 | 弱辅音/气声丢失、音乐噪声、WER 上升 | 只在低 SNR 启用；`nr≤12`；A/B 校准阈值 |
| 去混响 | 发闷、辅音模糊 | 仅极低 SNR；参数轻；文档明确局限 |
| 响度归一化 | 动态模式压缩、抬高底噪 | `LRA=30`；`TP=-2`；复测 LRA |
| VAD 裁剪 | 切断词头/弱起音 | 只裁首尾；250 ms 余量；语音时长告警 |
| 多次重采样 | 高频损失、相位失真 | 全链路只重采样一次 |
| 强 EQ / 压缩 / 限幅 | 谱包络改变，模型失配 | 不启用 |

## 7. 未知输入的默认安全方案

当音频属性未知（用户直接拖入文件、来源不明）时，按以下顺序执行：

1. **只读探测**：ffprobe + 指标测量，不修改文件。
2. **保守链**：16 kHz / mono / s16 → 80 Hz 高通 → 两遍 loudnorm（线性优先）→ 首尾静音裁剪。
3. **默认不降噪、不去混响、不压缩中间静音**，除非指标触发（SNR < 19 / < 12）。
4. **保留原始文件**，输出 `{id}.asr.wav` 与 `{id}.prep.json`；预处理失败自动回退原始 WAV。
5. **给出明确警告**：削波、SNR < 10 dB、静音占比 > 60%、语音时长异常减少、LRA 大幅下降。

这样即使判断错误，最坏结果也只是"没有改善"，而不是"把可识别语音处理坏"。

| `MSHK_PREP_DEREVERB` | `auto` | `auto/on/off` |

| `MSHK_PREP_SILENCE_DB` | `-38` | 静音判定阈值 |

| `MSHK_PREP_MIN_TRIM_S` | `0` | 首尾静音短于该值时不裁（混响场景可调 1.5） |
| `MSHK_PREP_TRIM_MID` | `1` | 是否压缩超长中间静音 |

| `MSHK_FFPROBE` | 自动 | ffprobe 路径 |

## 9. 局限

1. **SNR 是估计值**，不是仪器测量；不同增益下绝对值不可比。
2. **多人说话无法分离**；报告只标记"疑似对话"，需人工复核或外接 diarization。
3. **ffmpeg 无真正去混响**；强混响请用 WPE / DeepFilterNet。
4. **WER 只在带参考文本的合成语料上计算**；真实临床录音没有逐字稿，只能用前后文本一致性作为间接证据。
5. **不能修复削波**；削波失真不可逆，只能提示重录。
6. **混响检测缺失**：估计 SNR 不反映混响，去混响不会自动触发；且混响下 VAD 边界不稳定（多条样本评估见 [MULTISAMPLE.md](../outputs/audio-preprocess/MULTISAMPLE.md)）。
