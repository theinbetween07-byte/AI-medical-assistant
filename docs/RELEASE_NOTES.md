# MedScribe HK v1.0.1

香港临床口述病历助手首个可分发版本：把粤语 / 英语 / 中英混合口述整理为可校审的结构化病历初稿。
全部推理在本机完成，不上传音频、不联网下载模型。

## 安装

1. 下载 `MedScribe-base-v1.0.1.7z`，用 7-Zip 解压，得到 `MedScribe` 文件夹。
2. 双击 `MedScribe\MedScribe.bat`，等控制台显示三段服务就绪（首次 10–30 秒）。
3. 浏览器自动打开 <http://127.0.0.1:8100>。关闭控制台或双击 `stop.bat` 停服。

安装扩展（可选，按需选一个或多个）：

1. 下载对应扩展包（分卷要全部下载并放在同一文件夹），解压第一个文件，得到 `MedScribe-ext`。
2. 把 `MedScribe-ext\app` 复制到 `MedScribe\` 根目录并合并（覆盖同名文件）。
3. 重启 `MedScribe.bat`，在工具条「模型」选择新模型。Qwen3 首次转写加载约 20–60 秒。

未安装的扩展在下拉中显示「未安装」，点击弹出下载地址与步骤，不会联网下载。

Whisper medium / large-v3 扩展沿用基准数据：平均错误率 13.0% / 9.2%（GPU），CPU int8 耗时约为 small 的 2–3 倍 / 5–6 倍。基准为合成语料、每场景 1 条，方向性参考；77 次运行明细见仓库 `outputs/ui-integration/asr-benchmark/REPORT.md`。

## 系统要求

- Windows 10 / 11 64 位
- 4 GB 内存（Whisper large-v3 扩展建议 16 GB）
- 磁盘：基础包 908 MB；扩展按需再加 1.4 GB（medium）/ 2.9 GB（large-v3 或 Qwen3）
- 显卡：不需要，默认 CPU int8；Qwen3 扩展可选 Vulkan 加速

## 已知限制

- 未接真实患者数据、未连 EHR；报告必须由有资质医师逐项核对签署。
- 粤语真人、中英混合、真实噪声未覆盖，现有数据为 SAPI 合成语料。
- 扩展引擎以 PyInstaller 打包，未在无关机验证过运行库兼容性。
- Windows localhost 偶发连接重置，已做有界重试，仍可能重试耗尽后报错。
- 病理报告有两处标签内部切分问题（`tumour_grade` 为空、`tumour_type` 混入分级），待修。

## 隐私

音频转码、ASR、模板抽取全部在本机完成；除用户主动导出文件外不产生外部请求。

## 2026-11-07 修复：再次启动后界面元素缺失

- 根因：静态资源 URL 的版本串固定不变，且响应缺少 `Cache-Control`，浏览器按启发式缓存继续使用旧的 `app.js` / `app.css`，与新的 `index.html` 混搭导致元素缺失。
- 修复：资源 URL 改为按文件内容哈希生成，首页禁止缓存，静态资源每次回源校验（命中 ETag 仍 304）；启动脚本会比较已运行进程的构建版本，发现旧版本自动重启。
- 无需用户手动清缓存：重新解压基础包并启动后，页面会自动拉取与 HTML 同版本的前端资源。

## 2026-11-07 新增：识别语言可选与自动识别

- 转写工具条新增「语言」下拉：自动识别（默认）/ 中文 / 粤语 / 英语 / 日语 / 韩语，选择会被记住。
- 之前不传语言时后端默认按粤语解码，普通话录音容易被识别成无意义音节；现在默认自动识别，也可手动指定。
- 选择语言后再转写，转写结果上方的语言标签会显示实际使用的语言与置信度。

## 2026-11-07 新增：识别语言可指定

- 还没新建会话时也能先选识别语言；选项新增法语、德语、西班牙语、俄语、葡萄牙语、意大利语、阿拉伯语。
- 「自动识别」仍是默认项；手动指定后按该语言解码，中文术语提示词不再干扰其他语言。
- 选择会被记住，下次打开沿用。

## 2026-11-08 修复：Firefox 下「刷新」没有反馈

- 安装引导的「刷新」现在一定会给出结果：检测到模型时变绿提示；没检测到会显示刷新时间，并提醒确认是否解压到了程序目录。

## 2026-11-08 修复：模型装在别的目录时检测不到

- 安装引导新增「检测位置」，直接告诉你程序在哪个目录找模型，方便对照自己解压到了哪里。
