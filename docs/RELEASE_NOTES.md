香港临床口述病历助手首个可分发版本：把粤语 / 英语 / 中英混合口述整理为可校审的结构化病历初稿。

## 安装

1. 下载 `MedScribe-base-v1.0.1.7z`，用 7-Zip 解压，得到 `MedScribe` 文件夹。
2. 双击 `MedScribe\MedScribe.bat`，等控制台显示三段服务就绪（首次 10–30 秒）。
3. 浏览器自动打开 <http://127.0.0.1:8100>。关闭控制台或双击 `stop.bat` 停服。

安装扩展（可选，按需选一个或多个）：

1. 下载对应扩展包（分卷要全部下载并放在同一文件夹），解压第一个文件，得到 `MedScribe-ext`。
2. 把 `MedScribe-ext\app` 复制到 `MedScribe\` 根目录并合并（覆盖同名文件）。
3. 重启 `MedScribe.bat`，在工具条「模型」选择新模型。Qwen3 首次转写加载约 20–60 秒。

未安装的扩展在下拉中显示「未安装」，点击弹出下载地址与步骤，不会联网下载。

## 系统要求

- Windows 10 / 11 64 位
- 4 GB 内存（Whisper large-v3 扩展建议 16 GB）
- 磁盘：基础包 908 MB；扩展按需再加 1.4 GB（medium）/ 2.9 GB（large-v3 或 Qwen3）
- 显卡：不需要，默认 CPU int8；Qwen3 扩展可选 Vulkan 加速

## 已知限制

- 未接真实患者数据、未连 EHR；报告必须由有资质医师逐项核对签署。
- 粤语真人、中英混合、真实噪声未覆盖，现有数据为 SAPI 合成语料。
- 扩展引擎以 PyInstaller 打包，未在无关机验证过运行库兼容性。
- Windows localhost 偶发连接重置，已做有界重试，仍可能重试耗尽后报错。
- 病理报告有两处标签内部切分问题（`tumour_grade` 为空、`tumour_type` 混入分级），待修。

## 2026-11-07 修复：再次启动后界面元素缺失

- 根因：静态资源 URL 的版本串固定不变，且响应缺少 `Cache-Control`，浏览器按启发式缓存继续使用旧的 `app.js` / `app.css`，与新的 `index.html` 混搭导致元素缺失。
- 修复：资源 URL 改为按文件内容哈希生成，首页禁止缓存，静态资源每次回源校验（命中 ETag 仍 304）；启动脚本会比较已运行进程的构建版本，发现旧版本自动重启。
- 无需用户手动清缓存：重新解压基础包并启动后，页面会自动拉取与 HTML 同版本的前端资源。

## 2026-11-07 新增：识别语言可选与自动识别

- 转写工具条新增「语言」下拉：自动识别（默认）/ 中文 / 粤语 / 英语 / 日语 / 韩语，选择会被记住。
- 之前不传语言时后端默认按粤语解码，普通话录音容易被识别成无意义音节；现在默认自动识别，也可手动指定。
- 选择语言后再转写，转写结果上方的语言标签会显示实际使用的语言与置信度。

## 2026-11-07 新增：识别语言可指定

- 还没新建会话时也能先选识别语言；选项新增法语、德语、西班牙语、俄语、葡萄牙语、意大利语、阿拉伯语。
- 「自动识别」仍是默认项；手动指定后按该语言解码，中文术语提示词不再干扰其他语言。
- 选择会被记住，下次打开沿用。

## 2026-11-19 修复：转写更准、标点恢复、不会再重复跑

- **不会再重复转写**：同一个会话已经有转写在进行时，再点「转写」（或开两个标签页点）会直接复用那个任务，不会重复上传、重复解码，也不会出现「等了三遍时间」的情况。
- **标点与分句恢复**：长录音按 30 秒分块解码，块内保留上下文，转写结果重新带上逗号和句号，段数减半、不再是几个字的碎片。
- **专名更稳**：同一段 72 秒音频，「血肠硅胃腱异常」这类错误回到「血常规未见异常」；长时间录音（约 5 分钟）不再出现重复句子或乱码。
- 速度基本不变：72 秒音频 5.8s（修复前 5.2s），5 分钟音频 21.2s（修复前 21.3s）。

## 2026-11-20 v1.0.3：把「填满」改成「填对」

一次收口 v1.0.2 之后发现的三类问题：规则分层口径不一致、字段归属错位、多处全量扫描；并补上字段级评测，用同一套语料验证方向。

**一、链路口径**

- **ASCII 词表加词边界**：`general practice` 不再因 practice 里的 ct 被判成「检查」，`positive for hepatitis B` 不再因 po 进「处理计划」，`labour` 不再命中 lab 标记词。中文仍按子串匹配，`follow up` / `follow-up` 两种写法都认，`5mg` 仍命中单位。
- **中文长句不再按字数硬切**：24 字兜底会把「一百二十八」切成「一百二十」+「八」、把「體溫」劈成「體」+「溫」。现在在目标长度附近按语义边界评分选切口：避开数字、小数、中文数词串、单位与英文单词；84 字无标点串由 24/24/36 变为 23/19/42，数值与术语完整。
- **分块解码增加 1 秒重叠**：60 秒硬切会落在词中间。现在块与块重叠 1 秒（`WHISPER_CHUNK_OVERLAP`），覆盖句丢弃、跨切口重复开头裁剪、截断半句由完整版替换。
- **标记词加权配置生效**：`marker_score` → `marker_bonus`（按实际生效值 1.6 写入），代码兼容老键。运行时读的是 `integration/terms` 那份副本，两份已对齐并加了跨目录同步测试——否则改引擎那份在打包版里是静默失效的。
- **LLM 调用上限按报告重置**：修掉进程内第二份报告后精修静默失效的问题。

**二、字段归属**

- **标题段落不再被关键词抢走**：病理 `MICROSCOPIC EXAMINATION` 之后的镜下描述只要出现 "invading through / lymph nodes / margins"，就会被搬进浸润深度、淋巴结状态、切缘字段，导致镜下检查整段为空、派生诊断继承污染。现在整句标题建立强作用域，段落内叙述一律归该字段；`Tumour site: …` 这类标签建立的弱作用域仍允许更具体的关键词优先。
- **查体续述与残句各归其位**：查体段「On examination, BP 128/76…」之后的「Throat is mildly injected, chest clear」此前无人认领；没有临床关键词的残句更会被静默丢弃。现在 O 段续写归上一字段，无关键词残句跟随上一句上下文，确实无上下文的进入「未覆盖内容」警告。
- **现病史不再被主诉顺手带走**：S 段零散叙述归模板声明的承接字段（现病史），「病人講喉嚨痛…」剥成「喉嚨痛…」。
- **重复值不再叠加**：synoptic 行与镜下重述同一事实，不再拼成 "present present"。
- **「病人今日覆診」不再进处理计划**：「覆診」既是计划词也是叙述词，按时间指向区分——有「今日/昨日/剛剛」且无「後/下次/安排/預約」时判为叙述。

**三、性能**

- 标签正则缓存 + 分区比较：300 句字段分配 71.1 → **10.0 ms**。
- 术语库首字符 + 长度索引：77 字术语纠正 21.3 → **9.2 ms**；15 段中英混合文本与旧算法逐一对比，替换结果与纠正记录完全一致。

**四、评测与验证**

- 新增 `report-engine/eval/`：14 例合成语料（7 病理 + 7 SOAP，中/英/粤）+ `run_eval.py`。同一语料：v1.0.2 44/52（84.6%）→ v1.0.3 52/52（100%），应空字段泄漏 0。
- 报告引擎 26/26、集成 63/63、后端 10/10，共 99 项全部通过。
- 内置病理样例填充 19 → 20（镜下检查从「未提及」变完整），SOAP 填充 7 → 8，字段级差异 9 处且全部为纠错方向。

**五、修复与体验（2026-11-21）**

- 撤销纠正不再把每个文字切片写成整段文段：`text_raw` 只记录纠正前文本，切分后清空，撤销只回滚真正替换过的分段。
- 转写进行中点「新建会话」不再无反应；选择音频后焦点回到本界面；模板选择写入会话，上传音频 / 切换会话 / 切换界面语言后不再被打回默认模板。
- 模板下拉按当前语言只显示「中文」或「English」一侧；新建会话默认名改为「11月21日 14:05」/「Nov 21, 14:05」，去掉「会话」前缀；转写按钮改为与「生成初稿」一致的主色。
- 启动后常驻系统托盘：菜单含打开界面、启动服务、停止服务、关于（显示版本 / 构建 / 规则 / 术语库版本）。
- 安装目录过深时提前提示：包根路径达到 120 字符，启动器会显示当前长度并停止启动；托盘启动前可二次确认。ASR 加载音频库失败时改为可读的「路径过长」说明，不再只报 `__reduce_cython__`。建议解压到 `C:\MedScribe` 这类短目录。

**未包含**：一句多事实拆分、抽取词表与模板词表合并、通用字段级错位校验。这三项需要真实标注语料（建议 20–30 份脱敏口述）才能量化收益；14 例合成语料只用于版本回归比较，不代表真实病历分布。
